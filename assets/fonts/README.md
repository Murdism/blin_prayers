# Bundled fonts

The app bundles these fonts so its Blin/Ge’ez and English typography does not
depend on a network connection:

- Noto Sans Ethiopic variable font
- Noto Serif Ethiopic variable font
- Cormorant Garamond variable regular and italic fonts

The font files were retrieved from the corresponding official Google Fonts
repositories. They are distributed under the SIL Open Font License 1.1; the
complete licence texts are stored beside the font binaries as
`OFL-Noto-Ethiopic.txt` and `OFL-Cormorant-Garamond.txt`.
